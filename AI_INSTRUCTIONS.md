# AI Instructions

## Before Editing

1. Read `AI_CONTEXT.md`.
2. Read `PROJECT_MANIFEST.json`.
3. Read `DEV_LOG.md`.
4. Confirm current project status.
5. List files that will be modified.

## During Editing

- Keep changes small.
- Avoid unrelated refactoring.
- Avoid deleting files without explicit request.
- Preserve existing user-facing text unless editing is requested.

## After Editing

- Update `DEV_LOG.md`.
- Explain changed files.
- Mention any commands the user needs to run.
